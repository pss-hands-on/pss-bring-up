# PSS operation-model labs

Companion to `../slides.md`. Each lab is one PSS operation model, generated by
`pssc` and driven by three small environments (C, SystemVerilog, Python). Each
environment puts a fake device behind the model's import API, so everything
runs on a laptop.

| Lab | Topic | Device |
|---|---|---|
| `lab1/` | Core structure: component tree, init, export/import functions | 2-channel timer, raw offsets |
| `lab2/` | Registers and memory: SystemRDL → PSS register model, programming sequences | same timer, register model |

## Prerequisites

From the repo root, `uvx ivpm update` and `direnv allow` (see `../README.md`)
put `pssc`, `peakrdl` (with peakrdl-pss), `verilator` and `python3` on PATH.
You also need `gcc`.

- `pssc` comes from source. To use a different source tree, pass
  `make ... PSSC_SRC=~/projects/psstools/pssc`.
- Lab 2, `make regs` only: the generated `pss/timer_regs_pkg.pss` is checked
  in, so you can skip this step.

## Running

```sh
cd lab1
make help
make gen          # all four flavors into gen/{sv,c,cpp,py}
make run          # C, SV, Python harnesses: all three print the same bus trace
make run SOL=1    # the exercise solution (solution/)
```

## Layout (per lab)

```
pss/          the operation model (the deliverable)
env/c         C harness:      pssc_mem_read32/write32 + plat_delay_us, fake device
env/sv        SV harness:     class implementing <root>_imp_if, create(), fake device
env/py        Python harness: object with read32/write32/plat_delay_us
solution/     the same tree with the exercises done
rdl/          (lab2) SystemRDL source of the register model
```

## pssc notes (as of 2026-10-14)

- `op-model-c` with `--mem-access functions` **and the default `--link-style mmio`**
  still lowers raw `read32`/`write32` to a pointer dereference, so a host harness
  segfaults. The labs pass `--link-style direct --mem-access functions`, which
  lowers correctly.
- `--link-style vtable --mem-access ...` is a user error, but it is reported as an
  internal error with a traceback (exit 2).
- Register structs narrower than the register give a C union with a `uint8_t raw`.
  The labs use `peakrdl pss --pad-tail` to avoid this.
- Hex literals in PSS come out decimal in SV/C (`0x7A11` → `31249`). This is cosmetic.
